## Despliegue (NO ejecutado; requiere orden del dueño y fila en el ledger)
⚠️ Escribir userdata BORRA el Android actual (apps y datos de usuario de HyperOS). Para volver a Android:
`fastboot erase userdata` + `erase metadata` antes del primer arranque (LV-R1).
```
sha256sum build/rootfs/rootfs-uke-l76-8g.img   # == 7e4309f0…
fastboot flash userdata build/rootfs/rootfs-uke-l76-8g.img   # fastboot lo envia en trozos sparse
bash docs/historia/gates-palawan/flash-l76r-gated.sh                         # boot_a = L76R (o flash-l76-gated.sh)
```
Cargador de pared conectado (en fastboot no carga), lector ACM armado y batería >= 3700 mV.
